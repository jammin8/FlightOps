## Frozen head-contract collision

The existing `join_contract.HEAD` requires a non-null `replaced` boolean. This selected courier contains no replacement-history state. Neither the current selected SHA, opening receipt, merged status nor absence of another head establishes that fact. The adapter therefore preserves the selected head in its wrapper observations and emits `heads=[]`, with `existing-head-contract-replaced-state-unavailable` and `head_bridge=unavailable-missing-replaced-state`. It does not manufacture false, rewrite the shared contract, or infer a head from a title, branch, trailer or clock.

The smallest future data remedy is an explicit selected-head projection carrying observed replacement state and its original provenance. Alternatively, the contract owner could separately review support for unknown replacement state. This packet requests no new capture and changes neither shared interface. Existing join input/output contracts accept the independent CI and policy rows without a head; the join has zero head-based CI eligibility. The wrapper retains one selected head observation, while the existing join's `pr_head_observations` denominator is zero. These are separate inventories.
